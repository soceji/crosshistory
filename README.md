# 역사의 갈림길

기원전 4000년부터 2100년까지, 실제 인구·수명·문해율 통계와 역사적 사건 위에서 한 나라를 이끄는 대체역사 시뮬레이션 게임.

- 시대: 채집(기원전 4000) · 고대(기원전 200) · 중세(1000, 1400) · 근대(1880) · 현대(1948)
- 고조선부터 대한민국까지 한국사 국가, 역사적 사건 약 190개, 역사 인물 60명, 기술 108개
- 하루 단위 진행, 1·2·3·5·10·15·30배속
- 실제 매장지 약 200곳의 지하자원(흑요석·소금·구리·주석·철·금·은·석탄·석유·우라늄·희토류)이 경제·기술·군사에 영향
- 기후: 고기후 복원과 관측·IPCC 전망 기반 세계 기온, 실제 지진대·화산의 확률적 재해와 역사 기록 속 대지진·대분화
- 채집·신석기 사회 전용 사건
- 군단 단위 전쟁: 공격/방어 태세, 지방에 군단 배치·진군, 지형별 공격·방어 가중치, 상륙 패널티, 병력·병참·무기 기술·장수 역량을 따지는 전투와 전술 선택, 포위
- 병참: 수도와 주요 지방에서 도로망을 따라 잰 거리로 지원률 결정
- 역사 인물 약 160명: 고유 효과 + 재상·장수·학자 직책 효과, 장수는 군단 지휘
- 선택에 따라 이어지는 연쇄 사건 30여 개
- 정부 부패도: 정체·영토·제도의 질·안정도에 따라 변하고, 세수·생산·연구를 깎는다. 영토가 넓을수록 척결 비용이 크다
- 항구: 해안 지방에 7단계 항구, 적합도(해안선·바다 이웃·결빙·옛 항구 도시)에 따라 교역 수입 차등
- 모든 기술에 경제·군사 효과, 중세 이후 중국·일본의 공터 채움
- 도로: 오솔길 → 흙길 → 포장 도로 → 역참 간선로 → 철도 → 고속도로 (기술에 따라 건설, 이동 속도·병참·생산에 영향)

## 실행

빌드된 `index.html` 하나로 동작한다. 브라우저로 열거나 GitHub Pages로 배포한다.

## 구조

| 파일 | 내용 |
|---|---|
| `src/engine.js` | 시뮬레이션 엔진 (인구·경제·연구·전쟁·사건, DOM 없음) |
| `src/data.js` | 기술 계보, 정부, 정책, 시대별 국가, 실제 통계 |
| `src/events.js` | 역사 인물, 역사 사건, 무작위 사건 |
| `src/wardata.js` | 전투 지형·산악/구릉 지대·도로 등급·전술 |
| `src/people.js` | 추가 역사 인물, 연쇄 사건 |
| `src/nature.js` | 지하자원·기후·지진·화산 데이터, 자연재해 기록, 선사 시대 사건 |
| `src/ui.js` | 지도 렌더링, 패널, 사건 모달 |
| `src/map.js` | 지방 지도 데이터 (Natural Earth 1:50m 기반 0.25° 격자) |
| `src/mapgen.js` | `map.js` 생성 스크립트 (`world-atlas`, `topojson-client` 필요) |

`src/`를 고친 뒤 `python3 build.py`를 실행하면 `index.html`이 다시 만들어진다.
