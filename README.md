# 역사의 갈림길

기원전 4000년부터 2100년까지, 실제 인구·수명·문해율 통계와 역사적 사건 위에서 한 나라를 이끄는 대체역사 시뮬레이션 게임.

- 시대: 채집(기원전 4000) · 고대(기원전 200) · 중세(1000, 1400) · 근대(1880) · 현대(1948)
- 고조선부터 대한민국까지 한국사 국가, 역사적 사건 약 190개, 역사 인물 60명, 기술 108개
- 하루 단위 진행, 1·2·3·5·10·15·30배속
- 실제 매장지 약 200곳의 지하자원(흑요석·소금·구리·주석·철·금·은·석탄·석유·우라늄·희토류)이 경제·기술·군사에 영향
- 기후: 고기후 복원과 관측·IPCC 전망 기반 세계 기온, 실제 지진대·화산의 확률적 재해와 역사 기록 속 대지진·대분화
- 채집·신석기 사회 전용 사건
- 군단 단위 전쟁: 공격/방어 태세, 지방에 군단 배치·진군, 지형별 공격·방어 가중치, 상륙 패널티, 병력·병참·무기 기술·장수 역량을 따지는 전투와 전술 선택, 포위
- 병참: 수도와 주요 지방에서 도로망을 따라 잰 거리로 지원률 결정
- 역사 인물 약 160명: 고유 효과 + 재상·장수·학자 직책 효과, 장수는 군단 지휘
- 선택에 따라 이어지는 연쇄 사건 30여 개
- 정부 부패도: 정체·영토·제도의 질·안정도에 따라 변하고, 세수·생산·연구를 깎는다. 영토가 넓을수록 척결 비용이 크다. 부패가 높을수록 군대 유지비가 급격히 늘어난다 (×(1+c+4c²))
- 인력: 인구와 제도(동원력)로 상한이 정해지고 매달 차오른다. 군대 모집·충원은 인력을 쓰고, 바닥나면 충원이 멈춘다. 충원 속도는 군단 위치의 병참 지원률을 따른다
- 군단 소모율(1 − 병력/정원)이 80%를 넘으면 군단이 흩어진다. 매복·포위 섬멸·유인 같은 계략이나 퇴로 차단으로 전투에서 군단이 통째로 궤멸할 수 있다
- 군단 이동 진행률: 이동 중 전투를 치러도 진행률이 유지되고, 이긴 뒤 그대로 행군을 잇는다
- 역사적 건물 36곳(피라미드, 만리장성, 첨성대, 불국사, 경복궁, 자금성, 수에즈 운하, 경부고속도로 등): 실제 착공 시점에 건립 사건, 땅을 가진 나라가 효과를 받는다
- 역사적 유물 128점(논어, 팔만대장경, 직지, 훈민정음 해례본, 동의보감, 프린키피아, 종의 기원 등): 인물이 활동할 때 「유물을 만든다 / 관련 기술 혁신에 매달린다」를 고른다. 수도를 빼앗기면 약탈당할 수 있다
- 사상가·발명가·예술가 89명 추가 (인물 총 249명) (공자부터 팀 버너스리까지)
- 역사 공부: 역사 사건·건물·유물·인물·질병 창에서 한국어 위키백과의 실제 사진과 해설을 불러와 보여 준다. 연대기·유산·인물 탭의 「사진·해설」 버튼으로 언제든 다시 볼 수 있다. 건물 36곳, 유물 128점, 정체 14가지와 제도 66가지에는 게임 안에 자세한 해설이 들어 있다 (작은 사진과 해설은 `photos.json`에 함께 묶여 있어 인터넷이 막힌 곳에서도 보이고, 위키백과에 연결되면 더 큰 사진으로 바뀐다. `node tools/export_queries.js`로 검색어 목록을 갱신해 푸시하면 GitHub Actions가 사진을 다시 받는다)
- 전염병: 천연두·흑사병·장티푸스·콜레라·홍역·발진티푸스·인플루엔자·코로나바이러스가 지방에서 지방으로(도로·항구·하늘길) 번지며 인구를 줄인다. 역사 속 대유행(안토니누스 역병, 흑사병, 콜럼버스의 교환, 스페인 독감, 코로나19 등)과 풍토병 유행
- 위생 수준(0~5): 기술·제도·위생 사업으로 올라가고, 전파율·감염률·치명률을 낮춘다. 역병이 닥치면 격리·구휼·국경 봉쇄·검사 추적 등의 대책을 고른다. 위생 대책 사건(우물, 검역, 혜민서, 존 스노, 지석영 등)
- 항구: 해안 지방에 7단계 항구, 적합도(해안선·바다 이웃·결빙·옛 항구 도시)에 따라 교역 수입 차등
- 모든 기술에 경제·군사 효과, 중세 이후 중국·일본의 공터 채움
- 도로: 오솔길 → 흙길 → 포장 도로 → 역참 간선로 → 철도 → 고속도로 (기술에 따라 건설, 이동 속도·병참·생산에 영향)

## 실행

빌드된 `index.html` 하나로 동작한다. 브라우저로 열거나 GitHub Pages로 배포한다.

## 구조

| 파일 | 내용 |
|---|---|
| `src/engine.js` | 시뮬레이션 엔진 (인구·경제·연구·전쟁·사건, DOM 없음) |
| `src/data.js` | 기술 계보, 정부, 정책, 시대별 국가, 실제 통계 |
| `src/events.js` | 역사 인물, 역사 사건, 무작위 사건 |
| `src/wardata.js` | 전투 지형·산악/구릉 지대·도로 등급·전술 |
| `src/people.js` | 추가 역사 인물, 연쇄 사건 |
| `src/events_kr.js` | 고려·조선의 세세한 사건 (실록 기반) |
| `tools/fix_map.js` | 바다 건너 흩어진 지방 조각을 정리하는 지도 보정기 |
| `src/heritage.js` | 역사적 건물, 역사적 유물, 사상가·발명가, 계략 전술 |
| `tools/` | 사진 검색어 목록 생성(`export_queries.js`)과 위키백과 사진 수집기(`fetch_photos.py`, GitHub Actions에서 실행) |
| `src/learn.js` | 사건·건물·유물·인물의 위키백과 문서 연결과 해설 |
| `src/disease.js` | 질병, 위생 제도, 방역 대책, 대유행·위생 사건 |
| `src/nature.js` | 지하자원·기후·지진·화산 데이터, 자연재해 기록, 선사 시대 사건 |
| `src/ui.js` | 지도 렌더링, 패널, 사건 모달 |
| `src/map.js` | 지방 지도 데이터 (Natural Earth 1:50m 기반 0.25° 격자) |
| `src/mapgen.js` | `map.js` 생성 스크립트 (`world-atlas`, `topojson-client` 필요) |

`src/`를 고친 뒤 `python3 build.py`를 실행하면 `index.html`이 다시 만들어진다.
